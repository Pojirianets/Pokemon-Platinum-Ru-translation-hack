# Pokemon-Platinum-Ru-translation-hack

## О проекте
Шестой проект по переводу игр серии Pokemon на русский язык. Перевод осуществлён с использованием глоссария от команды [Pokerus](https://pokerus.ru) и наработок с предыдущих проектов.

Перевод создан с помощью [sdsme](https://github.com/Skareeg/SDSME).
